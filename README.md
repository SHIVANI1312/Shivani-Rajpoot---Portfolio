# Shivani Rajpoot | Product Manager Portfolio

Personal portfolio of Shivani Rajpoot, an aspiring Product Manager based in Bangalore. It is a single-file static website with no build step.

**Live site:** https://shivani-rajpoot.vercel.app *(update if your URL differs)*

## What's inside

- **Hero carousel** with three illustrated slides
- **About** and **tech stack** with a rotating sphere of tool logos
- **Experience** tabs: Timeline, Highlights ("My Growth Journey"), Skills, and Not in resume
- **Case studies**
  - Giftly: AI gifting assistant
  - Truecaller: Contact Pass
  - Embla.ai: personalised spaces
  - Group CHRO search: talent mapping for CXOs (with in-page PDF viewer)
  - Google Pay: Smart Search teardown ([repo](https://github.com/SHIVANI1312/google-pay-smart-search))
- **Contact** form that opens Gmail, Outlook or your email app with the message filled in
- Dark and light theme toggle, scroll animations, mobile-friendly layout

## Tech

Plain HTML, CSS and JavaScript in one file (`index.html`). Images are embedded inline, and fonts load from Google Fonts. There are no dependencies.

## Run locally

Open `index.html` in any browser. That's it.

## Deploy

**Vercel:** import this repo as a new project, or connect it to an existing one. Framework preset: **Other**. No build command and no output directory. Every push to `main` redeploys automatically.

**GitHub Pages:** Settings, Pages, deploy from branch `main`, folder `/ (root)`.
